HOW TO PLAY
  1. Explore the City Grid — 8 districts: Logic, HTML, CSS, JavaScript, Python, PHP, SQL and React.
  2. Repair systems — fix broken code in the editor, then press RUN & VERIFY. Python runs on a real Python runtime; SQL executes on a live table engine; React renders live components.
  3. Answer logic probes — some missions are multiple choice. Read the code carefully.
  4. Voice feedback — the AI announces correct and wrong answers aloud. Toggle with the speaker icon.
  5. Earn XP & level up — every repair awards XP. Progress saves automatically on this device.
  6. Use hints — stuck? Tap the lightbulb for a hint, then read the explanation after each mission.
